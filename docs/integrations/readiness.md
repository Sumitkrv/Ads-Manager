# Ad account readiness

Google Ads and Meta Ads use the same deterministic checklist: business information, account ownership, identifier recorded, advertising permissions, website destination, conversion plan, billing responsibility and policy review.

The progress percentage is computed from required checklist rows that the current workspace administrator marked complete. Notes are user reports and reject language that claims external verification. A 100% score means preparation items were marked complete; it does not mean account ownership, permissions, billing, policy status, tag installation or campaign readiness was verified.

Account identifiers are limited to planning metadata. Secrets such as tokens, passwords, cookies, session IDs and payment credentials must not be entered.

All read/write access is workspace-scoped. Owners and admins can update planning records; members with read permission can view them. Each mutation creates an append-only actor/time audit entry.
