# Measurement privacy planning

Implementation plans record a destination, measurement provider/method, non-secret identifier, consent prerequisites, test plan, owner label, review state and a privacy checklist covering privacy notices, consent, jurisdiction review, minimization, sensitive fields, retention and third-party sharing.

This is planning support, not legal advice or a compliance certification. No website tags are injected, no visitor data is collected, and no real event payload is sent. Synthetic test parameters reject common email/long-identifier shapes and use small strict schemas.

Do not include personal information, credentials, payment data, session identifiers or raw visitor IDs in event parameters, notes or UTM values.
