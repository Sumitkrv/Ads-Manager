# Conversion goals and event definitions

Goals are versionable workspace planning definitions with a business category, internal event name, objective, optional illustrative value/currency, counting policy and attribution notes. Saving a goal does not report a conversion.

Industry presets are explicitly user-triggered, editable and idempotent by internal event name. The catalogue includes real estate, education, fitness, clinics, ecommerce, automobile, hospitality and agency examples. Presets never overwrite existing campaign, creative, Brand Kit or reporting data.

Event keys are internal uppercase identifiers. Definitions describe source type, trigger, expected parameter types, required fields, consent and deduplication reference. Provider event names are stored separately in mappings. GA4 public recommended names can be shown as suggestions; custom Tandem event keys are not described as provider-standard names.

Goal, event and mapping records are workspace-scoped and writable by owners/admins. Changes are audited. Archived records remain available for history.
